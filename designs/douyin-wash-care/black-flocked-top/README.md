# 黑色植绒拼接上衣｜抖音洗护详情页

## 设计目标
对应用户提供的**黑色半高领植绒长袖＋奶白拼接下摆**商品参考图。与其他店铺的面料护理排版保持区分，采用黑色主标题、米白底色、暖棕线条和双列护理卡片，重点突出“**即使同为黑色衣物也不要混洗**”。

## 本次成品
- 聊天中提供可直接下载的高清 PNG：1200 × 1810 像素，抖音商品详情页可用。
- 聊天中同时提供可编辑 SVG（包括参考截图提取的商品图与中文矢量排版）。
- 本仓库保存相应护理文案和 Midjourney 背景提示词；由于 GitHub 连接器仅按文本创建文件，本次没有把本地含商品照的 PNG/SVG 二进制成品同步到仓库，**不得将仓库说明误写成已经存有成品图**。

## 视觉规范
- 主色：黑色 #262523，暖米白 #F4F0EA，浅褐 #E6DDD2，铜棕 #A88D73。
- 结构：大字号主标题＋商品参考照片；黑底“单独洗涤”提示横幅；两列六张护理卡；底部拼接衣物提醒。
- 比例：1200×1810，适合竖向商详滚动。
- 商品图片以真实商品为准，Midjourney 只用于非商品的抽象背景、绒面肌理氛围元素，不用它凭空补造衣服的结构/材质。
- 所有中文文字应在可编辑的 SVG / Canva / Figma 或其他排版工具中录入，避免 Midjourney 出现乱码。

## 洗护真实性与风险
所写洗涤建议需由商品实物洗标核对，若洗标要求干洗或禁止水洗，**以洗标为准，不能沿用手洗建议**。不可宣称“明显掉色和串色都属于正常现象”，也不要擅自排除退换货权利。
