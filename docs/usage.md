# 使用说明

## 调用
在 Codex 中打开仓库，使用 `$womenswear-trend-topics` 加任务描述。未识别时明确要求读取 `.agents/skills/womenswear-trend-topics/SKILL.md` 后执行。GitHub 写入不等于其他产品中的技能安装。

提供平台、时间、人群、商品、真实价格与成分、出镜条件、素材、目标、数量。未知项可省略，技能会标出假设。

```text
使用 $womenswear-trend-topics。
平台：抖音；时间：近7天；人群：普通女装。
主推秋冬半身裙，目标是短视频引导进入直播，给5个选题。
只有样衣，拍手部和细节，不出镜。
真实热点附原文与日期，证据不足就给常青选题，口语化，不夸张逼单。
```

```text
使用 $womenswear-trend-topics，核查近30天与女装材质宣传、
发货、素材授权有关的抖音官方规则变化。
列出生效日期、适用对象、需要检查的页面与话术，未核实到的不要下结论。
```

## 输出
选题表带证据类别和优先级；优先选题有3秒开场、15–30秒分镜、直播承接、物料、风险检查与复盘方式。只问规则时输出核验表和操作清单。完整示例见[示例输入输出](../.agents/skills/womenswear-trend-topics/references/output-examples.md)。

## 边界与复盘
- 实时热点执行时检索，示例不是当日榜单；不保证爆款或申诉通过。
- 发布前核对商品、成分、尺码、价格、库存、发货承诺及素材授权。
- 公共仓库不存顾客信息、订单、密钥或内部经营数据。
- 监控、通知、自动发布需独立设置，技能不会后台运行。
- 发布后24小时和72小时记录发布时间、版本、播放、有效观看、完播、互动、商品点击、直播进入、成交与指标口径。只对比同账号相似内容，一次调整一个主要变量；没有基线先积累数据。
