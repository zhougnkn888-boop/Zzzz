# 来源与规则核验

## 检索顺序
1. 平台政策优先抖音电商官方规则中心和商家后台官方公告；涉及微信小店则查其官方规则。实际检索确认入口，不编造公告地址。
2. 内容信号查原始作品、话题页和公开榜单，核对发布时间与可见指标。不可访问私有数据时明确说明。
3. 行业趋势查包含时间、样本和口径的原始报告。媒体解读仅作线索，回溯原文。
4. 查询词组合“品类＋日期＋实穿/搭配/搜索趋势”或“平台＋女装＋规则＋修订”。不拿搜索摘要代替完整规则。

## 证据记录
记录标题、发布主体、原文URL、发布日期、事件/数据日期、检索日期、指标口径、可见事实、推断及局限。链接紧邻判断。

单条热门视频不能证明全平台趋势；不同账号、日期、统计口径不直接比较。缺日期、不可访问或无原文时降低置信度，列待补材料。

## 规则核对
| 项目 | 核验要求 |
| --- | --- |
| 官方性 | 找到发布主体及正文，自媒体不能单独证明新规 |
| 时间 | 区分发布与生效，识别征求意见稿和失效版本 |
| 范围 | 区分店铺/达人、类目、活动、地区与过渡期 |
| 变化 | 有新旧文本才能比较；只有新版就只说明当前要求 |
| 操作 | 映射到成分、主图详情、直播话术、素材授权、发货和售后 |
| 冲突 | 优先最新有效官方文本，无法解决则列待核实问题 |

示例不构成现行政策。没有核实到公告不等于平台没有变化。
