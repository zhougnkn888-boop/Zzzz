# 聚水潭服装 ERP 助手

这是一个面向服装电商日常运营的聚水潭 Skill。

主要覆盖：
- 商品编码 / 商家编码 / 款号 / SKU
- 商品编码缺失、乱码、批量补编码
- 颜色尺码商品资料维护
- 订单与库存查询
- 销退在途 / 销退进仓
- 退货位置查询
- 商品与平台 SKU 映射
- 抖店 / 视频号等平台同步异常
- Excel 批量修改与数据整理
